# Instruction inventory — October 1, 2026

This is the modernization audit, not another agent instruction layer. Each row
identifies a distinct instruction or closely coupled procedure and assigns
exactly one disposition. Repeated copies share their original owner; historical
facts remain evidence rather than new instructions. Searches covered the
requested phrases across entrypoints, hooks, configuration, source, automation
definitions, readiness and operational docs. Runtime schema fields and tests
were traced separately from conversational requirements.
