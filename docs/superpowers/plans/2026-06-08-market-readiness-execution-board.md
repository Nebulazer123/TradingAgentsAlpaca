**How To Use This Board**

- Start each work session from `AGENTS.md`, `CONTEXT_ROUTER.md`, this board, and `results/_context/latest-summary.json` / `latest-flags.json`.
- Pick the highest-priority unchecked item whose prerequisites are met.
- Say the board ID you are working on before editing.
- When a slice is completed, change `[ ]` to `[x]`, add date, packet/test evidence, and the exact verification command or report path.
- Do not redo completed work just because it appears in an older plan. If new evidence disproves a completed item, add a dated child row under the same ID and explain the regression.
- Before any final close-out, reconcile every requirement, weak area, score gap, and exact-command task from `docs/superpowers/plans/2026-06-08-finish-overnight-research-control-plane.md`, `reports/market_readiness/market-readiness-goal-assessment-20260608.md`, and `reports/market_readiness/market-readiness-goal-assessment-20260608.json` into this board. Each item must map to a completed board row, an open board row, or a newly added row with priority and evidence target.
- If a source file exposes a stale, broken, weaker, or silently degraded system path, do not accept it as "good enough"; either restart/fix that path until the stronger route works, or add an explicit open P0/P1 row that names the exact remaining fix.
- Do not create a second tracker. If more detail is needed, add it here or point to a packet/report from the item row.
- Engineering, docs, tests, n8n staging, and git cleanup should proceed without artificial blocker language. Real money movement remains controlled by the current live gate and repo safety checks.

**Definition Of Done For The Whole Program**

- `main` contains every accepted implementation slice; the WIP branch is preserved, merged or superseded, and no useful file is stranded.
- `git status --short` is explainable: clean, or only intentionally local ignored/sensitive runtime state.
- Overnight research completes with current source-quality review, provider bundles, original-graph outputs, and a fresh premarket brief.
- The original TradingAgents graph is used deliberately where it adds value; fallback paths are bounded and visible.
- No required analyst report silently comes back empty; LLM calls have timeout/retry/max-token controls where long reports can hang or truncate.
- MiroFish and Deep Research are ingested as advisory market-behavior gates, especially bot-crowding, institutional-liquidity adaptation, macro override, broker-friction, and attribution-error checks.
- Buy and sell decisions are independent: sells are not blocked by buy caps, losses trigger review instead of automatic panic exits, and buys prefer controlled pullbacks over green-spike chasing.
- Agent Intelligence Ledger resolves mature forecasts across all tickers, computes calibration/relative-return metrics, and uses earned influence instead of equal votes.
- Walk-forward and paper-tournament results include costs/slippage and can constrain live influence when weak.
- n8n has allowlisted jobs, discovery, dataset sync, native-eval status, and wide edge-case evaluation coverage while staying a wrapper around repo commands.
- Hooks and self-heal stay compact and timely: real trigger, real safe-plane fix attempt, real verification packet, no token-heavy raw packet reads unless flagged.
- Emails and dashboard messages are short, human-readable, and state the action, reason, blocker, and next check.
- Focused tests, process/eval reviews, department simulation, and full pytest pass or leave exact fix records.
- The three named source plans/assessments are fully reconciled into this board; no P0/P1 source requirement is merely cited, forgotten, or hidden in a superseded file.
