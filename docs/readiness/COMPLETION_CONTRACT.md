# Readiness completion contract

Load this contract only when the task is to continue readiness work. The durable
acceptance owner is the
[twelve-phase plan](../superpowers/plans/2026-08-30-tradingagents-evidence-first-working-state-completion.md).
Current progress lives in [CURRENT_STATUS.md](CURRENT_STATUS.md) and
[PROGRESS.md](PROGRESS.md); historical evidence stays in linked checkpoints.

## Finish line

Complete research qualification, legitimate dated stock/cohort identity, the
prospective development/validation/owner-released holdout lifecycle, source-bound
learning reconciliation, current readiness evidence, and the final integrated
source gate. Complete one qualifier plus five additional real clean market
sessions in the existing twelve-stage order and retain the existing reset rules.
A reproducible null or negative study result is acceptable. Missing evidence is
an incomplete requirement. None of these results grants trading authority.

## Continue and record

Take the next dependency-ready item from current progress, follow its plan
section and verify its actual acceptance. Continue independent useful work when
a dependent step lacks access, elapsed market time or separate authority. Keep
current decisions, changes, checks, exact blockers and next actions in progress;
keep immutable experiment/recovery evidence in its existing owners. Report deltas.
The plan's recorded worktree/role assignments apply to that readiness run, not
unrelated source tasks; current task instructions select participation.

## Native Goal suitability

The program is a good fit for a thread-scoped Codex Goal because its next action
depends on evidence gathered across turns. Its existing completion contract is
sufficient until the owner explicitly asks to create a native Goal. No Goal or
token cap is created by reading this file. A requested Goal should reference this
finish line and the actual verification surfaces; paid runs, holdout release,
schedule activation and broker actions retain their separate scope. See
[Using Goals in Codex](https://developers.openai.com/cookbook/examples/codex/using_goals_in_codex).
